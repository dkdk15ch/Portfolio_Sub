Roots プロジェクト案内

==================================================
1. プロジェクト全体
==================================================

Rootsは、植物の根を伸ばしてマップ上の資源を運ぶゲームのプロトタイプです。
DxLibを使用してマップと根を描画し、マウス入力による根の選択・作成を行います。

大まかな処理の流れ
  main.cpp
    -> MapManager
       -> マップブロックの読み込み、更新、描画
    -> RootManager
       -> 根の生成、更新、削除、修復
    -> Player
       -> プレイヤーの更新、根の選択状態の管理
    -> 各ゲームオブジェクト
       -> Run、Drawによる更新と描画

==================================================
2. エントリーポイント・ゲームオブジェクト
==================================================

main.cpp                 Windows/DxLibのエントリーポイントです。
  DxLib、マップ、プレイヤー、根の管理クラスを初期化し、
  ゲームループを実行します。

gameObject.h              更新と描画を行うゲームオブジェクトの共通インターフェースです。

Player.h                  プレイヤーの位置、根の選択状態、選択中の根を管理します。
  プレイヤーの更新と描画を行います。

InputManager.h            マウスの現在フレームと前フレームの入力を管理します。
  左クリックの押下中・トリガー・リリース、右クリックを判定します。

Tree.h                    マップ上の木のサイズ設定、更新、描画を担当します。

playerInfo.h              プレイヤー情報を保持します。

==================================================
3. マップ・ブロック
==================================================

mapList.h                 MapManagerを定義します。
  CSVからマップを読み込み、マップ上の全ブロックを更新します。

mapInfo.h                 マップ上の木とブロック画像の配置、描画を行います。

mapBlockBase.h            マップブロックの基底クラスです。
  座標、資源、画像、通過済み・公開済み・ウイルス状態、
  プレイヤーとの衝突を管理します。

blockFactory.h            BlockTypeに応じたマップブロックを生成します。

blockType.h               マップブロックの種類（砂、栄養、水、酸素）を定義します。

blockSand.h               砂ブロックを定義します。

blockNutrient.h            栄養ブロックを定義します。

blockWater.h              水ブロックを定義します。

blockOxygen.h             酸素ブロックを定義します。

==================================================
4. 根の生成・更新・接続
==================================================

IRoot.h                   根の共通インターフェースです。
  根の始点・終点、前後の根、資源コスト・獲得量、更新、描画、
  プレイヤーとの衝突を定義します。
  接続先がない場合に使用するNullRootも定義します。

rootBase.h                根の共通実装です。
  根の種類、始点・終点、前後の根、資源、
  終点との衝突判定を保持します。

rootManager.h             すべての根を管理します。
  根の一括更新、生成、完全削除、部分削除、修復、
  プレイヤーによる選択を行います。

rootFactory.h             RootTypeに応じて探索根と開拓根を生成します。
  既存の通過済みマスを確認し、根の終点を調整します。

rootScout.h               探索用の根（Scout）を定義します。
  探索根の更新と描画を行います。

rootPioneer.h             開拓用の根（Pioneer）を定義します。
  資源計算を含む開拓根の更新と描画を行います。

rootType.h                根の種類（Null、Scout、Pioneer）を定義します。

rootUtils.h               根の方向判定、マップインデックス取得、
  経路の通過済み状態更新などの補助処理を定義します。

==================================================
5. 資源・衝突・計算
==================================================

resource.h                栄養、水、酸素の資源量を保持します。
  資源の加算と固定資源の作成を提供します。

calcuResource.h           根の距離やマップ上の資源をもとに、
  根のコストと獲得資源を計算します。

collision.h               点と矩形の衝突判定を行うBoxCollisionを提供します。

box.h                     矩形の左・上・右・下の座標を表すBoxRectsを定義します。

point.h                   2次元座標を表すPointと、座標の変更を扱うMutaPointを定義します。

==================================================
6. 描画・画像・定数
==================================================

imgHandle.h               ブロックや木の画像を名前付きで読み込み、
  DxLibの画像ハンドルを管理します。

color.h                   描画で使用する色定数を定義します。

==================================================
7. テスト・デバッグ
==================================================

Test.h                    根の生成、プレイヤーによる根作成、座標表示などの
  動作確認用処理を定義します。
  main.cppからテスト用の根生成とデバッグメッセージ表示に使用します。

==================================================
8. 実行時に参照するデータ
==================================================

roots_MapList.csv         MapManagerが読み込むマップデータです。
  マップ上のブロックの種類を定義します。

image/                    ブロックや木の画像を置くディレクトリです。
  画像管理クラスとmain.cppから参照します。

roots_MapList.csvとimage/は、実行時のカレントディレクトリから参照されます。
