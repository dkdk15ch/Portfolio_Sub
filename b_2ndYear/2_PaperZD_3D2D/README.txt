PaperZD_3D2D プロジェクト案内

==================================================
1. プロジェクト概要
==================================================

PaperZDを使用した2Dキャラクターによる会話・インタラクションの
ゲームプロトタイプです。

プレイヤーを操作して会話可能なキャラクターに近づき、インタラクション
入力で会話を開始します。会話中はデータテーブルから文章を順番に読み込み、
HUD上の吹き出しに表示します。選択肢がある場合は会話用の入力に切り替え、
回答結果に応じてイベントを実行します。

UE5.6の共通的なプロジェクト設定やビルド手順は省略しています。
本資料では、コードの構成と処理の流れを確認するための案内を記載します。


==================================================
2. プロジェクト全体
==================================================

・主なコードの場所
  Source/PaperZD_3D2D/
    プレイヤー、会話対象、HUD、ゲームモードなど、
    プロジェクト固有のC++クラスを配置しています。

  Source/PaperZD_3D2D/Public/
    公開用のウィジェットや共通ヘッダーを配置しています。

  Source/PaperZD_3D2D/Private/
    公開ヘッダーに対応する実装を配置しています。

・大まかな処理の流れ
  ACPPGM_MyGameModeBase
    -> UCPPW_HUDを生成して画面に追加
       -> UCPPW_Speechを会話用ウィジェットとして保持

  ACPP_Player
    -> 移動入力を受け取る
    -> BoxCollision内のインタラクション対象を検索
    -> ICPPI_Interactionを介して会話を開始・継続・終了

  ACPP_EnemyBase
    -> 会話データテーブルを非同期ロード
    -> 現在の行の文章を取得
    -> OnChangeDialogueでUCPPW_Speechへ通知

  UCPPW_HUD
    -> 会話者のワールド座標を画面座標へ変換
    -> 吹き出しの位置を毎フレーム更新


==================================================
3. ゲーム進行と入力
==================================================

プレイヤーの初期化
  CPP_Player.h
    プレイヤーキャラクターのクラスです。
    カメラ、スプリングアーム、インタラクション判定用の
    BoxCollision、移動用・会話用の入力マッピングを管理します。
    BeginPlay時にプレイヤー初期化用の通知を送信します。

  MyPlayerController.h
    プレイヤーのPossess時に入力設定を受け取り、
    Enhanced Inputのマッピングコンテキストを登録します。
    会話開始時は移動用の入力を会話用へ切り替え、
    会話終了時に移動用へ戻します。

入力の切り替え
  通常時
    移動入力を有効にし、プレイヤーを操作します。

  会話時
    プレイヤーの移動をロックし、会話の選択肢切り替えなど
    会話用の入力を有効にします。


==================================================
4. インタラクションと会話
==================================================

インタラクションの共通インターフェース
  CPPI_Interaction.h
    会話などのインタラクション対象が実装するインターフェースです。
    Interact、NextText、FinishInteractionを定義しています。
    プレイヤーは具体的なクラスを直接判定せず、
    このインターフェースを通して対象を操作します。

会話対象
  CPP_EnemyBase.h
    PaperZDのキャラクターを基底にした会話対象です。
    キャラクター名、現在の会話行、会話データテーブルを管理します。
    会話開始、次の文章への移行、会話終了を実装しています。
    会話終了時の固有イベントはBlueprintで実装できます。

  FCPP_DialogueData.h
    会話データテーブルの1行を表す構造体です。
    会話本文と次に読む行名を保持します。

会話の状態遷移
  Interact
    会話対象の現在行を読み込み、会話ウィンドウを表示します。

  NextText
    次の行がある場合は文章を更新します。
    次の行がなく、選択肢がある場合は選択肢を表示します。
    続きがない場合は会話の先頭行へ戻します。

  FinishInteraction
    会話ウィンドウを閉じ、会話状態を初期化します。
    YESが選択されていた場合はBlueprint実装の終了イベントを呼び出します。


==================================================
5. HUDとウィジェット
==================================================

HUD
  CPPW_HUD.h
    会話用の画面UIを管理するUserWidgetです。
    Speechにバインドされた吹き出しウィジェットを保持します。
    会話中のみTickを有効にし、会話者の位置に合わせて
    吹き出しを画面上へ配置します。

会話吹き出し
  CPPW_Speech.h
    会話者名、会話本文、会話者アクターを保持するウィジェットです。
    フェード、選択肢の表示、選択肢の切り替え、文章更新を
    Blueprintイベントとして公開しています。
    プレイヤーと会話対象のデリゲートを購読し、
    会話内容や選択状態の変更をUIへ反映します。

ゲームモード
  CPPGM_MyGameModeBase.h
    HUDウィジェットを生成してViewportへ追加します。
    生成したHUDをキャッシュし、会話対象から取得できるようにします。

簡易ウィジェット
  WCPP_Trump.h
    UserWidgetを継承したウィジェットの基底クラスです。
    現在の実装では、Blueprint側で利用するための空のクラスです。


==================================================
6. デリゲートによる通知
==================================================

プレイヤーからの通知
  CPP_Player.h
    OnPlayerBeginPlay
      プレイヤーの初期化後、PlayerControllerへ入力設定を通知します。
    OnChangeAnswer
      会話中の選択肢切り替えをSpeechへ通知します。
    OnChangeIMC
      通常入力と会話入力の切り替えをPlayerControllerへ通知します。

会話対象からの通知
  CPP_EnemyBase.h
    OnChangeDialogue
      データテーブルから取得した会話本文をSpeechへ通知します。

UI間の通知
  CPPW_Speech.h
    OnStopTick
      吹き出し位置の更新停止をHUDへ通知します。

==================================================
8. 確認時のポイント
==================================================

・会話データテーブルの行名がCPP_EnemyBase.hの
  CurrentNameRowと一致していることを確認してください。

・会話対象のBlueprintでは、DialogueDataTableRef、
  MyName、CurrentNameRowを設定します。

・HUDのBlueprintでは、CPPW_HUD.hのSpeechプロパティに
  会話吹き出しウィジェットをバインドします。

・フェード、文章、選択肢の見た目や終了時の固有処理は、
  CPPW_Speech.hおよびCPP_EnemyBase.hが公開する
  Blueprintイベント側で設定します。
