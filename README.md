# ポートフォリオ_サブ成果物

過去制作のソースコードです。
※サブ成果物になります。  

> **このリポジトリについて**  
> GitHub上でソースコードを確認するためのリポジトリです。  
> ビルド物は一部を除き、基本的に含みません。
> 実際の動いてる様子はGitHub Pagesの学習履歴ページをご覧ください。

## リポジトリ内容
- 学習履歴に乗せた成果物のソースコードです。
- 年次ごとに、新しいものから順にならんでいます。

- メイン成果物は含みません。別途GitHubに挙げているので↓を参照ください。
- URL: https://github.com/dkdk15ch/Portfolio_main.git


## コード詳細
- 詳細なファイルの説明は、
各成果物フォルダのREADME.txtにまとめてあります。

### ビルド済みゲームの配布
- ビルド物に関しては、アセットをパッケージが可能な
PrideBattleのみ用意しています。

### 必要な環境
- **OS:** Windows 10 / 11 (64-bit)
- **GPU:** DirectX 12 対応グラフィックボード
- **備考:** エンジンフォルダ（Engine）が同梱されているため、Unreal Engine本体のインストールは不要です。`PrideBattle.exe` から直接起動できます。
  *(※Microsoft Visual C++ 再頒布可能パッケージの導入が必要な場合があります)*
