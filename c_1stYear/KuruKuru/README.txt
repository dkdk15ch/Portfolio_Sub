DxLib / くるくるめくる プロジェクト案内

==================================================
1. プロジェクト概要
==================================================

本をめくる操作で、ページの呪文を覚え強くなっていく
コマンドバトルゲームです。

ストーリー中の選択イベントや
チュートリアル、プレイガイドも実装されています。

画面サイズ
  640 x 480

主な入力
  マウス操作       ボタン選択、ページ切り替え、タイミング操作
  ESCキー          ゲーム終了


==================================================
2. プログラム全体
==================================================

・エントリポイント
  DxLibの初期化、画像・サウンド・フォントの読み込み、
  メインループ、画面更新、終了処理をまとめています。

・初期化の流れ
  デルタタイム、フォント、ストーリー、アニメーション、
  タイトルUIを初期化した後、プレイヤー・敵・イベント画像と
  サウンドを読み込みます。

・大まかなゲームの流れ
  タイトル
    -> ①ストーリー
    -> ②バトル
    -> ③選択イベント
　  -> ②③を繰り返す。

  プレイヤーのHPが0になるとゲームオーバーになります。
  ゲームオーバーまたはゲームクリア画面でクリックすると、
  プレイヤーや敵、習得呪文などを初期化してタイトルに戻ります。

・画面の種類
  SceneTransition.h
    Title          タイトル画面
    Story          ストーリー表示
    StoryChoice    ストーリー中のイベント選択
    Battle         敵との戦闘
    BookTurnOver   本のページ切り替えとタイミング操作
    GameOver       ゲームオーバー画面
    GameClear      ゲームクリア画面


==================================================
3. ゲーム進行と画面遷移
==================================================

SceneTransition.h
  現在の画面をScreenTypeで管理し、画面遷移を行います。

Title.h
  タイトルロゴと開始ボタンを描画します。
  開始操作が行われるとストーリー画面へ遷移します。

Story.h
  ストーリー本文、ページ内の画像、選択イベントを管理します。
  イベントの結果に応じてプレイヤーの状態や次の展開を決定します。

PlayGuide.h
  操作説明やプレイガイドの表示状態を管理します。
  バトル中に開くことができ、表示中はゲーム操作を一時停止します。

Battle.h
  戦闘ターンの更新、プレイヤーの攻撃、チュートリアル、
  戦闘ログを管理します。

ゲームサイクル
  入力取得
    -> 現在の画面の更新
    -> キャラクター・本・UIの描画
    -> アニメーション状態の更新
    -> 次のフレームへ


==================================================
4. 本と呪文のシステム
==================================================

book.h
  本の左右ページ、ページ番号、ページめくり、
  タイミングバー、結果表示を管理します。
  ページを切り替えると、現在のページ内容に応じて
  呪文の確認や戦闘ターンの更新を行います。

magic.h
  呪文データ、習得済み呪文、呪文の完成判定、
  消費MP、ダメージ、追加効果を管理します。
  呪文には通常攻撃のほか、継続ダメージなどの効果があります。

fonts.h
  ストーリー、呪文、攻撃表示、プレイガイドなどで使用する
  フォントハンドルを管理します。

Text.h
  ストーリー本文、チュートリアル、操作説明などの
  ゲーム内テキストを管理します。


==================================================
5. プレイヤーと敵
==================================================

player.h
  プレイヤー画像、HP、MP、本のしおり表示を管理します。
  敵から受けたダメージによるHP更新や、状態の描画を行います。

Enemy.h
  敵の種類、HP、行動情報、行動までのターン数を管理します。
  攻撃・防御・特殊行動、敵のダメージ処理、行動ログ、
  敵画像の描画を担当します。

Battle.h
  プレイヤーと敵の行動を1ターン単位で進めます。
  敵撃破後はリザルトを表示し、次のストーリー選択または
  ゲームクリアへ遷移します。


==================================================
6. 入力・UI・アニメーション
==================================================

button_detection.h
  マウスカーソル位置、左クリックの前フレーム状態、
  ボタンの当たり判定、ドラッグ操作を管理します。
  ページ切り替えやNEXTボタンなどの操作に利用します。

animation.h
  ページめくり、プレイヤーと敵の攻撃、
  ヒット、ダメージ、フェードアウト、点滅表示を管理します。

Util.h
  画面サイズ、色、座標、矩形などの共通定義を管理します。
  テキストやボタンを中央揃えで配置する補助処理も含みます。

ScreenInfomation.h
  画面の幅・高さと、画面中央の座標を定義します。


==================================================
7. リソースと時間管理
==================================================

Sound.h
  攻撃、火、水、風、被弾、MP切れで使用する
  サウンドハンドルを管理します。

time.h
  フレーム間の経過時間を取得し、
  アニメーションや待機処理に使用するデルタタイムを管理します。


==================================================
8. 主な処理を確認する場所
==================================================

エントリポイント
  DxLibの初期化、各種リソースの読み込み、
  メインループと画面ごとの処理を確認できます。

SceneTransition.h
  画面の種類と画面遷移の入口を確認できます。

Battle.h / Enemy.h / player.h
  バトル中のターン更新、敵の行動、プレイヤーの
  HP・MP更新を確認できます。

book.h / magic.h
  本のページ処理、呪文の習得・判定・使用処理を確認できます。

Story.h / Text.h
  ストーリー本文、選択イベント、イベント結果を確認できます。

animation.h / button_detection.h
  画面演出とマウス入力に対する処理を確認できます。
